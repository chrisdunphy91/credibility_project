# research/

Unpublished working notes, one folder per topic (`research/<slug>/`), matching the topic page at `topics/<slug>.qmd`. Each folder contains:

- `sources.md` — annotated list of every study considered, with an inclusion/exclusion decision and a one-line reason.
- `notes.md` — extraction notes for included studies: citation, setting, design tier, outcomes, effect sizes with uncertainty, and caveats. Unverified items are marked `[VERIFY]`.
- `log.md` — dated log of searches run and decisions made.

This folder is excluded from the rendered site (see `project.render` in `_quarto.yml`). It is the evidence trail behind each page and may be published later for transparency, so keep it tidy and honest.
